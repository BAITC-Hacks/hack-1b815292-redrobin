# ИИ-агент анализа организационной структуры и функционала

## 1. О проекте

Проект разработан для автоматизации анализа организационных изменений.

Решение сравнивает документы до и после реорганизации, помогает определить
изменения в структуре подразделений, сопоставляет их функции и выявляет
потенциальные потери и дублирование функционала.

Для каждого существенного вывода система должна предоставлять ссылку
на подтверждающий фрагмент исходного документа.

Выводы системы носят рекомендательный характер и требуют проверки
ответственным сотрудником.

## 2. Какую проблему решаем

При реорганизации компании сотрудникам приходится вручную сравнивать
организационные структуры, положения о подразделениях, должностные
инструкции и другие документы.

Это занимает много времени и создаёт риск не заметить:

- потерю функции;
- дублирование функций;
- пересечение зон ответственности;
- потенциальный конфликт интересов.

Проект автоматизирует первичный анализ этих изменений.

## 3. Основной сценарий

1. Пользователь загружает документы «До реорганизации».
2. Пользователь загружает документы «После реорганизации».
3. Система извлекает информацию о подразделениях и их функциях.
4. Выполняется сопоставление данных «До» и «После».
5. Система выявляет потенциальные изменения и риски.
6. Пользователь получает результаты анализа с указанием источников.
7. Итоговые выводы проверяются ответственным сотрудником.

## 4. Что реализовано

> Этот раздел обновляется по мере разработки.

Планируемый основной функционал:

- загрузка документов;
- извлечение текста и структуры документов;
- определение подразделений;
- извлечение функций подразделений;
- сравнение состояния «До» и «После»;
- поиск потенциально потерянных функций;
- поиск потенциального дублирования;
- отображение подтверждающих фрагментов документов;
- формирование итогового аналитического заключения.

## 8. Как проверить решение

Для проверки необходимо загрузить контрольный набор документов
«До» и «После» реорганизации.

Ожидается, что система сможет обнаружить известные тестовые случаи:

- реорганизацию подразделения;
- потенциальную потерю функции;
- потенциальное дублирование функции;

и показать подтверждающие источники.

## 9. Данные и интеграции

Проект работает с документами, предоставленными для анализа.

Поддерживаемые форматы согласно требованиям кейса:

- PDF;
- DOCX;
- XLSX.

> Фактически реализованные форматы и внешние сервисы указать
> после завершения разработки.

## 10. Ограничения

Результаты анализа носят рекомендательный характер.

Система не должна формировать существенные выводы без подтверждения
исходными документами.

Окончательное решение по результатам анализа принимает ответственный
сотрудник.
